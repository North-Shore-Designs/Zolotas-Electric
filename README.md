# Zolotas Electric

Single-file website for **Zolotas Electric** — a second-generation, family-owned residential and commercial electrical contractor serving Essex County, MA and the North Shore of Boston, run by master electricians John and Greg Zolotas.

Built and designed by **Northshore Designs**.

## About the site

- One self-contained `index.html` file — no build step, no dependencies (fonts load from Google Fonts).
- Single-page app: Home, Services, Sub Contracting, Project Gallery, About, and Visit Us swap instantly via JavaScript.
- Interactive hero illustration (town lights up on a switch), light/dark mode, service catalog with detail modals, and a built-in rule-based assistant.
- Fully responsive with a mobile hamburger menu and sticky call/book bar.

## View it locally

Just double-click `index.html`, or open it in any browser.
